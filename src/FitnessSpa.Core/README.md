# FitnessSpa.Core

Доменный слой. Здесь размещаются основные сущности и бизнес-правила:

- `Client` — клиент фитнес-клуба;
- `Trainer` — тренер;
- `Membership` — абонемент и его ограничения;
- `Training` — тренировка или групповое занятие;
- `Booking` — запись клиента на занятие;
- `Locker` — шкафчик и его состояние;
- `Visit` — факт посещения.

Проект Core не должен зависеть от UI и конкретной СУБД.
