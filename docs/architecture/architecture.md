# Архитектура АИС «Фитнес-клуб и SPA»

## Логические компоненты

1. UI — отображает данные и принимает действия пользователя.
2. Application — выполняет сценарии работы с клиентами, абонементами, записями, посещениями и шкафчиками.
3. Core — содержит доменные сущности и правила предметной области.
4. Infrastructure — обеспечивает сохранение данных в PostgreSQL и взаимодействие с внешними системами.

## Основные потоки данных

- Клиент → UI → Application → Core/Infrastructure: оформление абонемента.
- Клиент → UI → Application → Infrastructure: запись на занятие.
- Сотрудник → UI → Application: регистрация посещения и выдача шкафчика.

Зависимости прикладного и доменного слоёв не должны напрямую определяться конкретной СУБД или пользовательским интерфейсом.
