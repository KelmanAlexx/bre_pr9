# АИС «Фитнес-клуб и SPA»

Учебный репозиторий для проекта автоматизированной информационной системы фитнес-клуба и SPA-центра (вариант 8).

## Назначение

Проект предназначен для поддержки основных процессов клуба:
- запись клиентов на групповые и персональные тренировки;
- учёт абонементов, сроков действия и оставшихся посещений;
- управление тренерами, расписанием занятий и залами;
- учёт шкафчиков и закрепления шкафчика за клиентом на время посещения;
- фиксация посещений и получение базовой отчётности.

## Структура

- `src/FitnessSpa.Core` — сущности предметной области и бизнес-правила;
- `src/FitnessSpa.Application` — сценарии использования и координация операций;
- `src/FitnessSpa.Infrastructure` — работа с БД, внешними сервисами и файловым хранилищем;
- `src/FitnessSpa.UI` — пользовательский интерфейс;
- `tests/FitnessSpa.Tests` — автоматизированные тесты;
- `docs/architecture` — архитектурные решения и схемы;
- `docs/openapi` — описание HTTP API.

## Предполагаемые технологии

- C# / .NET для прикладных модулей;
- PostgreSQL для хранения клиентов, абонементов, расписания, записей и шкафчиков;
- REST API для взаимодействия интерфейса с серверной частью;
- xUnit для модульного тестирования.

На данном этапе создан каркас репозитория и настроены правила Git. Реализация бизнес-функций будет выполняться в следующих этапах проекта.

## Работа с репозиторием

```bash
git status
git add .
git commit -m "Feat: add project module"
```

Для хранения крупных архивов и резервных копий используется Git LFS. После установки Git LFS выполните `git lfs install`; правила для `*.zip`, `*.7z`, `*.bak`, `*.dump` уже указаны в `.gitattributes`.
